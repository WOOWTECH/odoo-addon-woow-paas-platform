# 產生／更新方式：手動維護（本檔不是 --update-baseline 產出）

# 🔑 用途：**哨兵沒出現 ⇒ 這次跑的範圍不完整** ⇒ 本次所有差集結論一律不成立。
#   這比自造的邊界樣本強——它不是造出來的樣本，是真實環境裡必然存在的一條。
#
# 🔴 哨兵的判準是「**有沒有出現**」，不是「紅不紅」。

#     而「它必須出現在結果裡」這個要求在轉綠之後仍然完全成立。
#   ⇒ 真正該刪行的情況只有一種：那條測試**本身被移除或改名**（於是它永遠不會再出現，
#     哨兵會永遠紅）。刪之前先確認是這一種，不是「它現在綠了」。
