# Task: 新增 Odoo password 驗證

## Description

在 `_create_service()` 中為 Odoo template 新增 server-side 密碼驗證，確保使用者填入的 `odooPassword` 符合基本安全要求。複用現有 n8n password 驗證模式。

## Acceptance Criteria

- [ ] Odoo template 建立 service 時，`odooPassword` 需至少 8 字元
- [ ] 空密碼回傳明確錯誤訊息
- [ ] 驗證邏輯只在 Odoo template 生效（不影響其他 template）
- [ ] 錯誤訊息格式與現有 n8n 驗證一致

## Technical Details

### 目前 n8n 驗證邏輯（`src/controllers/paas.py:1329-1339`）

```python
if template.post_deploy_init_type == 'n8n':
    pwd = init_params.get('owner_password', '')
    if len(pwd) < 8:
        return {'success': False, 'error': 'Password must be at least 8 characters'}
    if not any(c.isupper() for c in pwd):
        return {'success': False, 'error': 'Password must contain at least one uppercase letter'}
    ...
```

### Odoo 驗證方案

在 `_create_service()` 的 value 過濾後、merge 前加入：

```python
# Validate Odoo password
if template.slug == 'odoo':
    pwd = helm_only_values.get('odooPassword', '')
    if not pwd or len(pwd) < 8:
        return {'success': False, 'error': 'Administrator password must be at least 8 characters'}
```

Odoo 的密碼驗證比 n8n 寬鬆（只要求長度），因為 Odoo 本身有密碼策略模組可進一步限制。
