# Task: Data migration 更新既有 Odoo template

## Description

建立 Odoo module migration script，確保已安裝模組的環境在升級後，既有的 Odoo template 資料能自動更新為新的 `helm_value_specs`（含 SMTP）和 `helm_default_values`（含 initContainer + 系統設定）。

## Acceptance Criteria

- [ ] Migration script 自動更新 `woow_paas_platform.cloud_app_odoo` record
- [ ] 更新 `helm_value_specs` 包含 SMTP 5 個欄位
- [ ] 更新 `helm_default_values` 包含 initContainer + proxy_mode + list_db
- [ ] 已部署的 CloudService records 不受影響（只更新 template）
- [ ] Migration 可重複執行不報錯（idempotent）

## Technical Details

### 版本號

需要在 `src/__manifest__.py` 中 bump version（如 `18.0.1.0.x` → `18.0.1.0.y`），migration script 對應新版本號。

### Migration 檔案

建立 `src/migrations/18.0.x.x.x/post-migrate.py`：

```python
import json
import logging
_logger = logging.getLogger(__name__)

def migrate(cr, version):
    """Update Odoo template with SMTP specs and system-level defaults."""
    # 更新 helm_value_specs
    new_specs = json.dumps({
        "required": [...],
        "optional": [...]  # 含 SMTP
    })

    # 更新 helm_default_values
    new_defaults = json.dumps({...})  # 含 initContainer

    cr.execute("""
        UPDATE woow_paas_platform_cloud_app_template
        SET helm_value_specs = %s, helm_default_values = %s
        WHERE slug = 'odoo'
    """, (new_specs, new_defaults))

    _logger.info("Updated Odoo template with SMTP and system settings")
```

### 注意事項

- `cloud_app_templates.xml` 的 `noupdate="1"` 區塊中的 Odoo template，升級時不會自動更新，必須透過 migration 手動更新
- Migration 和 XML data 的最終值必須一致

### 涉及檔案

- `src/__manifest__.py` — bump version
- `src/migrations/18.0.x.x.x/post-migrate.py` — 新建 migration script
