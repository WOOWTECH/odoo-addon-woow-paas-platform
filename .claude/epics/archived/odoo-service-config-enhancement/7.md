# Task: 更新 Odoo template — SMTP 欄位 + 系統層設定

## Description

在 `cloud_app_templates.xml` 中更新 Odoo template：
1. `helm_value_specs` 新增 SMTP 5 個欄位到 optional 區塊
2. `helm_default_values` 新增 initContainer 注入 `proxy_mode=True` 和 `list_db=False`
3. 整合 Task 001 的修復（如 customPostInitScripts）

依賴 Task 001 因為 `helm_default_values` 的最終內容取決於 bug 修復方案。

## Acceptance Criteria

- [ ] `helm_value_specs.optional` 包含：smtpHost, smtpPort, smtpUser, smtpPassword, smtpProtocol
- [ ] smtpProtocol 使用 `type: "select"`, options: `["ssl", "starttls", "none"]`, default: `"starttls"`
- [ ] smtpPort default 為 `"587"`
- [ ] `helm_default_values` 包含 initContainers 配置，注入 `proxy_mode = True` 和 `list_db = False` 到 odoo.conf
- [ ] 系統層設定（proxy_mode, list_db）不出現在 helm_value_specs 中
- [ ] 不填 SMTP 設定時，Odoo 正常部署

## Technical Details

### helm_value_specs 變更

```json
{
  "required": [
    {"key": "odooEmail", "label": "Administrator Email", "type": "text", "default": "user@example.com"},
    {"key": "odooPassword", "label": "Administrator Password", "type": "password"}
  ],
  "optional": [
    {"key": "loadDemoData", "label": "Load Demo Data", "type": "boolean", "default": false},
    {"key": "smtpHost", "label": "SMTP Server", "type": "text", "placeholder": "smtp.gmail.com", "description": "SMTP mail server hostname"},
    {"key": "smtpPort", "label": "SMTP Port", "type": "text", "default": "587", "description": "SMTP server port"},
    {"key": "smtpUser", "label": "SMTP Username", "type": "text", "placeholder": "user@gmail.com"},
    {"key": "smtpPassword", "label": "SMTP Password", "type": "password"},
    {"key": "smtpProtocol", "label": "SMTP Protocol", "type": "select", "options": ["ssl", "starttls", "none"], "default": "starttls"}
  ]
}
```

### helm_default_values — initContainers 配置

需要確認 Bitnami Odoo chart 的 initContainers 格式。Bitnami chart 支援：
```yaml
initContainers:
  - name: odoo-conf-injector
    image: busybox:latest
    command: ['sh', '-c', 'echo -e "
proxy_mode = True
list_db = False" >> /opt/bitnami/odoo/conf/odoo.conf']
    volumeMounts:
      - name: odoo-data
        mountPath: /opt/bitnami/odoo
```

注意：需確認 Bitnami chart 的 volume mount 路徑和 odoo.conf 位置。
