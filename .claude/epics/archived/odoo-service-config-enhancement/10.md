# Task: E2E 驗證 — 部署 Odoo 並驗證所有功能

## Description

在完成所有修改後，執行端對端驗證，確保三個功能點都正確運作：(1) 自訂帳密登入 (2) SMTP 設定生效 (3) 系統層 odoo.conf 已注入。

## Acceptance Criteria

- [ ] 建立 Odoo 服務時填入自訂 Email/Password，部署後可用該帳密登入
- [ ] admin/admin 預設帳號不可用
- [ ] 建立 Odoo 服務時填入 SMTP 設定，部署後 Odoo 的 outgoing mail server 已配置
- [ ] 不填 SMTP 時 Odoo 正常啟動
- [ ] `odoo.conf` 中包含 `proxy_mode = True` 和 `list_db = False`
- [ ] 短密碼（< 8 字元）在建立時被拒絕
- [ ] 模組升級（`-u`）後既有 template 正確更新

## Technical Details

### 驗證步驟

#### 1. 帳密驗證
```bash
# 建立 Odoo 服務（透過 UI 或 API）
# 填入 email: test@woowtech.io, password: TestPass123!

# 等待部署完成後：
# 1. 訪問 Odoo URL
# 2. 用 test@woowtech.io / TestPass123! 登入 → 應成功
# 3. 用 admin / admin 登入 → 應失敗
```

#### 2. SMTP 驗證
```bash
# 建立 Odoo 服務時填入 SMTP 設定
# 部署後檢查：
# Odoo Settings → Technical → Outgoing Mail Servers
# 應已有一筆 SMTP server 記錄

# 或直接檢查 Helm values：
helm get values <release> -n <namespace> | grep smtp
```

#### 3. odoo.conf 驗證
```bash
# 進入 Odoo Pod
kubectl exec -it <pod> -n <namespace> -- cat /opt/bitnami/odoo/conf/odoo.conf
# 應包含：
# proxy_mode = True
# list_db = False
```

#### 4. 密碼驗證
```bash
# API 測試：送出短密碼
curl -X POST /api/workspaces/<id>/services \
  -d '{"action": "create", "template_id": <odoo_id>, "name": "test", "values": {"odooEmail": "a@b.c", "odooPassword": "short"}}'
# 應回傳 error: "Administrator password must be at least 8 characters"
```

#### 5. 升級驗證
```bash
# 在既有環境執行升級
./odoo-bin -c odoo.conf -u woow_paas_platform --stop-after-init

# 檢查 template 是否已更新
# Odoo Shell:
# env['woow_paas_platform.cloud_app_template'].search([('slug','=','odoo')]).helm_value_specs
# 應包含 smtpHost 等欄位
```
